# Contributors

**ChatGPT is the main contributor and co-author of this documentation, in collaboration with Hans Schenker.**

| Contributor | Contribution |

| [Hans Schenker](https://github.com/hansschenker) | Project author and maintainer. Provided the RxJS dataflow perspective and direction for the notation, documentation, and publication. |
| **ChatGPT (OpenAI)** | Main contributor and co-author. Developed the initial notation analysis, explanations, operator reference, TypeScript examples, and VitePress documentation. |

The documentation grew from a discussion about why Haskell's types are concise and how the same clarity could help people read RxJS operator types. Its central proposal is `operator :: C → T* → R*`, supported by explicit descriptions of timing, cancellation, and sharing.

ChatGPT is credited as an AI collaborator. The project is maintained by Hans Schenker. The initial documentation was prepared in November 2026 and uses RxJS 7.8.2 as its technical reference.

The repository also keeps this attribution in [CONTRIBUTORS.md](https://github.com/hansschenker/rxjs-type-notation/blob/main/CONTRIBUTORS.md). Primary technical references are listed in [sources and scope](/reference/sources).
